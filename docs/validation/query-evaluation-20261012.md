## 实际交付

`deploy/evaluate_queries.py` 提供默认离线的固定样本回放；`--model-config` 是后续真实请求的显式开关，另有整批时间和估算费用上限。回放只创建临时实例，覆盖示例存储路径，不操作已有数据库。复用真实归档、Parser、入库、索引和只读 Agent，不以研究脚本的简化模型替代业务接口。

`human_review` 新增 `prepare --queries` 和查询标签 v2。完整语料、问题/时钟、合成画像、有效模型设置、限制、回答与版本证据绑定；工程候选期望剔除。既有规则/搜索标签 v1、46项历史记录和统计继续兼容。完整相关集与 supported / unsupported / incomplete / not_answered 独立记录；本地检索和失败回退不能标为 supported。更正、stale 和冲突保持显式处理。

固定输入见[九例清单](query-cases.json)，使用方法与统计口径见[查询评价](../query-evaluation.md)。
