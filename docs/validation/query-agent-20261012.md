2026-10-12。按用户选择实现 OpenAI Chat Completions 接口，真实调用稍后配置。本节点不部署生产实例，不改变 N2 从 2026-10-11 12:50:19 开始的七天观察窗口，不更新通知政策、Parser 或数据库结构。

## 交付

- `ask` / `ask-config-check`、独立查询 TOML 示例；配置路径锚定配置文件，帮助和校验不打开数据库、读取密钥或联网。
- UC、CS 跨实例搜索、分块通知读取、显式画像和来源状态工具；通知按实例与通知 ID 定位。实际读取的版本固定，原文引句、来源 URL、内容摘要和版本可追溯。
- 同步模型适配器与有限工具循环；逻辑调用、实际请求、工具数量、返回字符、运行时间和按配置单价估算的费用均有上限。模型失败保留已取得的检索候选。
- 程序按显式时钟计算有限的发布日期范围；直接读取通知 ID 也遵守范围。发布日期与报名期限分开，资格、附件条件与不支持的时间表达式保持未知。

接口与具体边界见[查询说明](../query-agent.md)。不增加依赖、表、索引或 Agent 框架，复用既有只读搜索和通知事实规则。未修改 research/报告及 fixture、既有 Parser、schema、历史迁移、依赖声明和锁文件。

## 尚未验证与限制

- 尚未配置真实模型、密钥或实际单价；没有真实 API 请求、供应商账单、模型相关性/工具选择质量或人工答案评价。MockTransport 不等于真实网络验收。
- 引文校验保证文本确实来自本轮读取内容，不能证明模型选择该句的语义正确，也不能证明检索没有漏报。事实提取沿用规则 v8；附件和图片仅保留引用。
- 运行预算为合作式检查，不能强制抢占文件、SQLite、DNS 或 CPU；费用为应用估算，不是供应商账单保证，没有跨查询的账户消费账本。
- 不写入聊天或查询结果、不联网补抓、不修复索引；覆盖过期、待处理和失败复查会明确展示。跨实例没有同一时刻的共同快照。
