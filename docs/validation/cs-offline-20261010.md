# CS 离线解析与决策回归摘要

本记录描述选取后的脱敏离线输入。仓库保留三页 CS 列表结构样本和一页通知样本；联系方式已移除，元数据摘要对应脱敏文件。评估画像为合成示例，不含真实院校、院系、专业或入学年份。完整逐例输出已压缩为 [汇总 JSON](cs-offline-current.json)。

## 覆盖范围

- CS 列表 Parser 验证页码、总页数、相对路由、可见行数和末页禁用链接。
- 通知 Parser 验证身份、标题、站点日期、正文结构和明确保留的未知事实。
- 决策回归覆盖合成本科/研究生兴趣变化，以及一份既有 UC 通知的正负例。
- 工程期望用于回归，不是人工金标、个人资格判断或当前招聘开放证明。
- 只保留逻辑第 1、2、4 页；没有第 3 页，因此不代表完整历史扫描。

汇总记录保留 Parser/规则版本、源码与清单摘要、案例数量和 Action 计数；逐例事实、Profile 展开和重复正文均不在汇总文件中。先前的全量逐例快照未随本次裁剪历史提交。

## 结果边界

当前 CS 招聘回归仍要求人工核对资格、时间和外部申请渠道。代码不根据标题学年补齐落款冲突，不从入学年份推定高年级，也不下载腾讯文档或访问群文件。JSP 路由只在测试中使用显式静态字节，不据此宣称匿名 HTTP 正文可用。

执行入口与 Parser 契约见[实现说明](../cs-undergrad.md)。更新规则时保留固定案例输入与明确工程期望，并重新生成汇总；不要把工程期望改称人工标签。
