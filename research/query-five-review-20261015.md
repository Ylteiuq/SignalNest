## 2. 人工核对入口

完整材料只在本机受限目录，含原文、既有回答和画像副本；不提交仓库。人工复核时先按问题看25篇原文判断相关性，再看实际结构化答案核对资格、期限与未知的使用；独立填写模板也保存在该本机材料包中。当前5题均pending，所有人工字段为null。
- 可直接在聊天中按[简短人工核对表](query-five-human-review-20261015.md)逐题回复，不要求操作JSON或命令行。
- 如怀疑材料池之外有漏检，可在本机材料包中查645身份目录与完整成功正文导出。原失败身份也保留为无正文，不能当负例。

25篇是工程取样，不是相关集或留出集。选材包括已看到的答案和独立从数据库选出的反例，因此不是盲测。它覆盖本轮发布日期窗口的全部11份成功正文、全部7份标题明确的CS助教招募，以及少量教师征题、学生申报、考核、行政期限反例。人工只看25篇时，结论范围就是packet25；不能把它升格为全644篇召回率。

## 4. 两项评价分开填写

### A. 有没有漏掉相关通知

先按问题与时钟标完整相关集合`R`，并注明范围`packet25 / whole_successful_corpus644 / partial`。每篇可判相关、不相关、无法判断；未核对保持null，不能转成不相关。若相关集明确为空才填`[]`。

相关性不自动等于“现在可报名”或“本人合格”。请另列必须在答案解释的`must_answer_ids`，并说明历史招聘、已过期条目和弱相关成果推荐的处理口径；避免事后用系统实际只选三篇这一事实改写相关集。

之后对照原报告：`C`为所有`search_results`去重，`A`为最终`notices`，`read_notice`成功轨迹另列。区分：

- `R-C`：已有成功正文，但本轮检索未发现。
- `(R∩C)-A`：检索发现但未选进答案；再核对是未阅读、拒选、简短回答提示/模型自行选择，还是遗漏。当前`AnswerArgs`契约允许最多8篇，“至多三篇”是提示而非硬上限；没有取得旧运行提示全文，不能认定其遗漏就是该提示所致。**不直接叫检索漏召回。**
- 无成功正文/未适配引用：数据获取范围缺口，不算模型已经看过的负例。

只有人工确认且范围完整时才计算候选Recall和答案集合Recall；不跨库拼接排序算Recall@K。R为空时Recall=null，另报是否恰当拒选。部分人工标签只列具体问题，不给总体率。

### B. 回答是否正确使用证据

逐条核对**行动→主体/分支→必要条件→该主体该步骤期限→时效/未知/覆盖范围**。原句存在于正文，只证明文本来源；不能证明语义角色正确。分别记录错误位置、原句、正确角色及影响。

| 人工判断 | 使用条件 |
| --- | --- |
| supported | 关键断言有正确证据；限定、资格未知、年份冲突和范围未被藏掉。 |
| incomplete | 有用内容正确，但遗漏必须解释的类别、条件、期限或边界。 |
| unsupported | 至少一处关键断言缺依据，或错用学生/导师、报名/审核、开始/截止等语义。 |
| not_answered | 没形成可评价的回答。answered程序状态本身不能决定人工标签。 |

两项不合成一个总分。答案中的已选句用得正确，不能抵消漏检；检索不完整也不等于所有引句都是伪造。模板另存真人姓名/代号、实际核对时间、input_sha256与说明；本研究不代填真人结论。

## 6. 已完成和边界

**已验证的材料完整性：**原报告、10份绑定输入、两库及原配置/画像复制前后SHA一致；导出只读查询公开通知表；25份原始HTML匹配原响应SHA；答案身份/版本/摘要与固定数据库一致，所有选中引句是对应原文的连续文本。完整JSON与原文留在私有包，公开仅有限元数据。准备脚本只用标准库，不导入应用，不读credential，不打开生产库或调用模型。

**仍待真人：**五题相关集、必要答案成员、两轴判断与具体修正优先级。现有材料足够开始逐题核对，不能由Agent补成人工gold。**可延后：**整校发现召回、未读取附件、全部历史样本、人群泛化、供应方后端/随机性和实时知识库新鲜度；本轮不扩展架构或模型选型。

运行方式与环境见[实验说明](experiments/query_five_20261015/README.md)。五题入口来自[replay_query_snapshot.py](../deploy/replay_query_snapshot.py)；评价口径沿用[查询评价](../docs/query-evaluation.md)，但现有human_review的九篇输入格式不直接接受五题快照格式。本轮使用独立sidecar，不改kind伪装旧bundle，也不沿用旧标签。
